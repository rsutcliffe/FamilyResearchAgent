Sources

What backs each individual in the tree, broken into three categories: archive citations imported from your GEDCOM(s) (TNA, GRO, parish offices, etc. — these are the real provenance for legacy bands), accepted citations you've confirmed via the agent flow (Phase 2 evidence), and the agent search trail (queries the research agent has run — included for transparency, not as cited evidence).

Archive citations

Sourced from imported GEDCOM(s). These are real archive references — TNA classes, GRO indexes, parish-register fonds — backing each individual when they were imported.

Accepted citations

Citations you've confirmed through the agent's Accept Match flow. These contribute to the Bayesian posterior as Tier 1 evidence.

Agent search trail

Queries the research agent has run while looking for evidence. These are not citations — they're the search history, surfaced so you can see what's already been tried.
